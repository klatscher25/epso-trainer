# AST3 Datenverarbeitung, Analytik, Statistik (EPSO/AST/158/26)

Der Fachtest (30 Fragen, 40 Minuten, A–D, **Englisch**) verbindet Statistik, Datenverarbeitung und europäische Statistik. Gewichtung der Lernfragen laut `packages.json`:

| Bereich | Ziel |
|---|---|
| Descriptive statistics & data visualisation | 30 |
| Probability, sampling, estimation, hypothesis testing | 35 |
| Regression, classification & basic ML | 30 |
| Data processing: SQL, Python/R, cleaning, formats, databases | 35 |
| Data governance, quality, metadata, GDPR/EUDPR, open data | 30 |
| European statistics (Eurostat, ESS, Reg. 223/2009, Code of Practice, SDMX, NUTS) | 25 |
| Dashboards, BI and geospatial data (INSPIRE, GIS) | 15 |

Summe: 200. Rund 48 % entfallen auf Statistik und Regression, 18 % auf Datenverarbeitung, 28 % auf Governance und europäische Statistik, 8 % auf BI und Geodaten.

## Was du pro Bereich wissen solltest
- **Deskriptiv:** Lagemaße, Streuung, Quartile, Boxplot, Schiefe; passende Diagrammwahl. Lektion `ast3-10`.
- **Inferenz:** Verteilungen, zentraler Grenzwertsatz, Konfidenzintervalle, Tests, p-Wert, Fehler 1./2. Art.
- **Regression:** lineare und logistische Regression, R², Residuen, Overfitting.
- **Datenverarbeitung:** SQL, pandas/R, Bereinigung, Formate. Lektion `ast3-20`.
- **Governance:** Datenqualität, Metadaten, DCAT-AP, Datenschutz.
- **Europäische Statistik:** Rolle von Eurostat und ESS, Code of Practice (Prinzipien: z. B. Unabhängigkeit, Qualität, Vertraulichkeit), SDMX-Austauschstandard, NUTS-Klassifikation.
- **BI/Geo:** Dashboard-Prinzipien, Koordinatenreferenzsysteme, INSPIRE.

## Lernreihenfolge
1. Statistik-Grundlagen und Inferenz (größter Block).
2. SQL und Datenbereinigung durch eigenes Üben (kleine Datensätze).
3. Europäische Statistik: Begriffe und Institutionen lernen (Auswendigarbeit, aber lohnend).
4. Governance, dann Dashboards/Geo.
5. Simulationen mit Zeitlimit.
