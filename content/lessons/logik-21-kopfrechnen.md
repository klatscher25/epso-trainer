# Kopfrechnen: Tricks und Drills

Der Taschenrechner kostet Zeit durch Eintippen und Kontrolle. Mit ein paar Tricks bist du bei Prozentaufgaben oft schneller und merkst Tippfehler sofort.

## Prozentketten
- **10 %**: Komma um eine Stelle nach links. 10 % von 340 = 34.
- **5 %**: Hälfte von 10 %. 5 % von 340 = 17.
- **1 %**: Komma um zwei Stellen. 1 % von 340 = 3,4.
- Baue jeden Prozentsatz daraus: 35 % von 60 = 30 % (18) + 5 % (3) = **21**.
- 15 % = 10 % + 5 %. 12 % = 10 % + 2 × 1 %.

## Tausch-Trick
- x % von y = y % von x.
- 18 % von 50 ist schwer, 50 % von 18 = **9** ist leicht.

## Prozentuale Änderung
- (neu − alt) / alt. Von 80 auf 92: Differenz 12, 12 / 80 = 0,15 → **+15 %**.
- Teile immer durch den **Ausgangswert**.

## Rückrechnung
| Änderung | Rückweg |
|---|---|
| +25 % | −20 % |
| −20 % | +25 % |
| +50 % | −33,3 % |
| +20 % | −16,7 % |
| +10 % | −9,1 % |

- Regel: Faktor 1,25 → Rückfaktor 1 / 1,25 = 0,8.
- „Nach Aufschlag von 25 % kostet es 150" heißt: alt = 150 / 1,25 = **120**.

## Bruch ↔ Prozent
| Bruch | Prozent |
|---|---|
| 1/2 | 50 % |
| 1/3 | 33,3 % |
| 1/4 | 25 % |
| 1/5 | 20 % |
| 1/6 | 16,7 % |
| 1/8 | 12,5 % |
| 1/9 | 11,1 % |
| 1/10 | 10 % |
| 1/12 | 8,3 % |
| 3/8 | 37,5 % |
| 5/8 | 62,5 % |
| 7/8 | 87,5 % |

Lerne 1/8 = 12,5 % auswendig, den Rest leitest du ab (3/8 = 3 × 12,5).

## Verhältnisse kürzen
- 180 : 120 → durch 60 teilen → **3 : 2**.
- Halbiere oder teile durch 10, solange es geht, bevor du größere Teiler suchst.

## Schnelles Dividieren
- 2.450 / 49: 49 ≈ 50, 2.450 / 50 = 49 → Ergebnis genau **50** (2.450 = 49 × 50).
- Runde Divisor und Dividend in dieselbe Richtung und vergleiche mit den Optionen.

## Zinseszins und Wachstum
- 1,1² = 1,21 → zwei Jahre mit 10 % Wachstum sind **+21 %**, nicht +20 %.
- 1,1³ = 1,331.
- **72er-Regel:** Verdopplungszeit ≈ 72 / Wachstumsrate in %. Bei 6 % → 12 Jahre, bei 8 % → 9 Jahre. (Näherung, gut für 2–10 %.)
- Kleine Raten: (1 + p)(1 + q) ≈ 1 + p + q, solange p und q klein sind.

## Größenordnung prüfen
- 4.812 × 0,52 ≈ 4.800 × 0,5 = 2.400. Wenn der Rechner 24.000 zeigt, hast du dich vertippt.
- Zähle Nullen: Millionen / Tausend = Tausend.
