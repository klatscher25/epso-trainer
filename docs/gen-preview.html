1. num-1012 · prozent · Stufe 1

Wie viel Prozent der Warenexporte von Niederlande entsprachen im Jahr 2017 die Warenexporte von Finnland? (auf eine Dezimalstelle gerundet)

  1. A) 37,5 %
  2. B) 60,1 %
  3. C) 65,5 %
  4. D) 78,1 %
  5. E) 84,1 %

Richtig: B

  1. 1. Wert Finnland 2017: 167; Wert Niederlande 2017: 278 (Mrd. €).
  2. 2. Anteil = 167 / 278 × 100 = 60,1 %.
  3. Antwort: B) 60,1 %.

Tipp: Bezugsgröße ist der Wert nach „von“ bzw. „an“ – er steht im Nenner.

2. num-1025 · wachstum · Stufe 2

Wie hoch war die durchschnittliche jährliche Wachstumsrate des Energieverbrauchs von Frankreich zwischen 2010 und 2012 (konstante Rate, die in 2 Jahren zum gleichen Ergebnis führt)? (auf eine Dezimalstelle gerundet)

  1. A) −4,0 %
  2. B) −3,5 %
  3. C) −3,3 %
  4. D) −3,1 %
  5. E) −2,2 %

Richtig: C

  1. 1. 2010: 200; 2012: 187; Zeitraum: 2 Jahre.
  2. 2. Wachstumsfaktor insgesamt = 187 / 200 = 0,9350.
  3. 3. Jährlicher Faktor = 0,9350^(1/2) = 0,9670 → −3,3 % pro Jahr.
  4. Antwort: C) −3,3 %.

Tipp: Gesamtwachstum (−6,5 %) durch 2 teilen liefert einen etwas zu hohen Wert – Zinseszins wirkt mit.

9. num-1008 · wachstum · Stufe 3

Angenommen, der Energieverbrauch von Finnland steigt 2022 um 8 % gegenüber 2021. Um wie viel Prozent läge der Wert 2022 dann über dem Wert von 2020? (auf eine Dezimalstelle gerundet)

  1. A) 5,6 %
  2. B) 6,2 %
  3. C) 8,0 %
  4. D) 9,2 %
  5. E) 11,2 %

Richtig: C

  1. 1. 2020: 14; 2021: 14.
  2. 2. Wert 2022 = 14 × 1,08 = 15,12.
